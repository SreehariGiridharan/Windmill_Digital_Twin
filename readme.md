# Digital Twin Windmill (Web App)

This project is a web-based digital twin simulation of a windmill built using Unity WebGL. It visualizes real-time data and is accessible via any modern browser.

## Features
- 🌐 Developed using Unity WebGL for interactive web-based visualization
- 🔄 Live data streamed from a Windows system using Firebase Realtime Database
- ⚙️ CI/CD pipeline with GitHub Actions for automatic build and deployment
- 🚀 Deployed via GitHub Pages for easy online access

## Technologies Used
- Unity (WebGL)
- Firebase Realtime Database
- GitHub Actions (CI/CD)
- GitHub Pages

## Live Demo
[🌐 View the App](https://windmill-project.github.io/Windmill_Digital_Twin/)

## Setup Instructions
1. Clone this repository
2. Open the Unity project
3. Build for WebGL platform
4. Push to main branch to trigger CI/CD pipeline
